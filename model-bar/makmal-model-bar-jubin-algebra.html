Model

Nota guru: miskonsepsi lazim dan cara mengesan

Cadangan saya berdasarkan amalan pengajaran umum. Sahkan dengan DSKP dan pengalaman kelas anda.

  • Bar tidak berkadar. Murid lukis bahagian sama panjang walaupun nilai berbeza. Kesan: minta murid ramal bahagian mana paling panjang sebelum memasukkan nilai.
  • Salah pilih model. Menggunakan bahagian–keseluruhan untuk soalan "lebih daripada". Kesan: tanya "adakah dua kuantiti dibandingkan, atau satu keseluruhan dipecahkan?"
  • Nisbah dianggap nilai. Nisbah 3 : 2 dibaca sebagai 3 dan 2 ringgit. Kesan: tanya "berapa nilai satu unit?"
  • Unit tidak sama saiz. Dalam model perbandingan semua unit mesti sama. Alat ini memaksa saiz unit sama.

Ungkapan

Jubin x sengaja bukan gandaan bulat jubin 1 supaya murid tidak menyangka x ialah nombor tertentu. Corak berjalur bermaksud negatif.
